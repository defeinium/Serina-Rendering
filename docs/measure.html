How to measure consistentlyStand over the plan. A = south-west, B = south-east, C = north-east, D = north-west. Measure wall runs A→B, B→C, D→C and A→D. For an opening, measure its start from that wall's first corner. Ceiling points need offsets from two perpendicular finished walls; wall points need an along-wall offset and height above finished floor (AFFL).
